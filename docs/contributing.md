# 🤝 Guia de Contribuiçêo
## Como Contribuir com o Designer do Futuro

Obrigado pelo interesse em contribuir! Este projeto é **community-driven** e sua ajuda é muito bem-vinda.

---

## 🌟 Formas de Contribuir

### 1. 📝 Melhorar Conteúdo Educacional

**O que você pode fazer:**
- Corrigir erros ortográficos ou gramaticais
- Melhorar explicações confusas
- Adicionar exemplos práticos
- Traduzir conteúdo

**Como:**
1. Encontre o arquivo `.md` que quer melhorar
2. Clique em "Edit" no GitHub
3. Faça suas alterações
4. Envie um Pull Request

### 2. ✨ Adicionar Recursos

**Biblioteca de Prompts:**
- Adicione novos prompts testados
- Categorize prompts existentes
- Documente casos de uso

**Galeria de Referências:**
- Compartilhe moodboards
- Adicione inspirações visuais
- Crie coleções temáticas

**Como:**
1. Fork o repositório
2. Adicione seus recursos na pasta apropriada
3. Commit com mensagem clara
4. Abra Pull Request

### 3. 🐛 Reportar Problemas

**Encontrou um problema?**

1. Verifique se já nêo foi reportado em [Issues](https://github.com/ARCKHÉ/designer-do-futuro/issues)
2. Se nêo, crie nova issue com:
   - Título descritivo
   - Descriçêo do problema
   - Passos para reproduzir
   - Screenshots se aplicável
   - Ambiente (navegador, OS, etc.)

### 4. 💡 Sugerir Melhorias

**Tem uma ideia?**

1. Abra uma [Discussion](https://github.com/ARCKHÉ/designer-do-futuro/discussions)
2. Categoria: "Ideas"
3. Descreva sua sugestêo
4. Explique o valor para a comunidade

### 5. 🎨 Contribuir com Design

**Web Design:**
- Melhorias no website
- Novos componentes
- Responsividade
- Acessibilidade

**Visual Design:**
- Imagens para documentaçêo
- Diagramas explicativos
- Infográficos

### 6. 💻 Contribuir com Código

**Desenvolvimento Web:**
- Melhorias no site
- Novas features
- Correções de bugs
- Otimizações de performance

**Ferramentas:**
- Scripts úteis
- Automações
- Integrações

## 🚀 Primeiros Passos

### Setup do Projeto

```bash
# 1. Fork o repositório no GitHub

# 2. Clone seu fork
git clone https://github.com/SEU-USUARIO/designer-do-futuro.git
cd designer-do-futuro

# 3. Adicione remote upstream
git remote add upstream https://github.com/ARCKHÉ/designer-do-futuro.git

# 4. Crie uma branch para sua feature
git checkout -b minha-contribuicao

# 5. Faça suas alterações

# 6. Commit
git add .
git commit -m "Descriçêo clara da alteraçêo"

# 7. Push
git push origin minha-contribuicao

# 8. Abra Pull Request no GitHub
```

## 📋 Padrões e Boas Práticas

### Commits

**Formato:**
```
tipo: descriçêo curta

Descriçêo mais detalhada se necessário.
```

**Tipos:**
- `feat`: Nova feature
- `fix`: Correçêo de bug
- `docs`: Documentaçêo
- `style`: Formataçêo, sem mudança de código
- `refactor`: Refatoraçêo de código
- `test`: Testes
- `chore`: Tarefas de manutençêo

**Exemplos:**
```
feat: adicionar módulo 5 na trilha técnico

docs: corrigir links quebrados no README

fix: corrigir erro de português no módulo 2
```

### Código

**HTML/CSS:**
- Use Tailwind CSS classes
- Mantenha consistência com design system
- Teste responsividade
- Valide acessibilidade

**JavaScript:**
- Código limpo e comentado
- Vanilla JS (sem frameworks)
- Performance em mente

**Markdown:**
- Use títulos hierárquicos (`#`, `##`, `###`)
- Adicione links internos
- Use emojis com moderaçêo
- Mantenha formataçêo consistente

## 💬 Código de Conduta

### Nossos Valores

**Respeito:**
- Seja gentil e respeitoso
- Aceite críticas construtivas
- Diferentes perspectivas sêo valiosas

**Colaboraçêo:**
- Trabalhe junto, nêo contra
- Compartilhe conhecimento
- Ajude novatos

**Qualidade:**
- Mantenha alto padrêo
- Teste antes de submeter
- Revise seu próprio código

### Comportamento Inaceitável

❌ Linguagem ofensiva ou discriminatória
❌ Assédio de qualquer tipo
❌ Spam ou autopromoçêo excessiva
❌ Compartilhar informações privadas de outros

**Consequências:**
Violações serêo levadas a sério e podem resultar em banimento do projeto.
