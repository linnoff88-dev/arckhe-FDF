### Aula 2: DALL·E via Bing Image Creator

**Duração:** 2 horas

#### Por Que Começar Aqui?

✅ Totalmente gratuito
✅ Baseado em DALL·E 3 (melhor do OpenAI)
✅ Sem necessidade de conta Microsoft (mas recomendado)
✅ Interface simples
✅ Resultados excelentes

#### Como Usar - Passo a Passo

**1. Acesse**
- Vá para: [bing.com/create](https://www.bing.com/create)
- Faça login com conta Microsoft (ou crie uma grátis)

**2. Escreva Seu Prompt**
- Use tudo que aprendeu no Módulo 3
- Escreva em português ou inglês (inglês geralmente melhor)

**3. Clique em "Criar"**
- Aguarde 10-30 segundos
- Receba 4 variações

**4. Escolha a Melhor**
- Clique para ver em tamanho maior
- Baixe (botão de download)

**5. Itere Se Necessário**
- Ajuste o prompt
- Gere novamente
- Repita até satisfeito

#### Dicas Específicas Bing/DALL·E

**O Que Funciona Bem:**
- Fotografia realista
- Ilustrações digitais
- Arte conceitual
- Cenas detalhadas
- Composições complexas

**Limitações:**
- Textos em imagens (pode sair errado)
- Rostos de celebridades (bloqueados)
- Conteúdo violento ou NSFW (filtrado)
- Logos de marcas (bloqueados)

**Prompts Otimizados Para Bing:**

```
❌ Evite: "crie uma imagem de..."
✅ Use: Descrição direta

Exemplo:
"Uma moderna cozinha minimalista branca com ilha central,
fotografia profissional de arquitetura de interiores,
luz natural entrando por grandes janelas,
plantas decorativas, atmosfera clean e acolhedora,
8k, ultra detalhado"
```

#### Formatos e Download

**Resolução:**
- 1024x1024 (quadrado) - padrão
- Ou especifique no prompt: "widescreen", "portrait orientation"

**Formato:**
- Download como JPG ou PNG
- Clique direito > Salvar imagem

### Aula 3: Leonardo.ai e Ideogram

**Duração:** 2 horas

#### Leonardo.ai - Arte e Versatilidade

**Setup Inicial:**
1. Acesse [leonardo.ai](https://leonardo.ai)
2. Crie conta gratuita
3. Receba 150 tokens diários

**Interface:**
- Mais complexa que Bing
- Mais controles e opções
- Maior curva de aprendizado

**Recursos Principais:**

**1. Modelos Diferentes**
Escolha o modelo:
- Leonardo Diffusion XL (geral)
- Leonardo Vision XL (fotográfico)
- Anime Pastel Dream (estilo anime)
- RPG 4.0 (fantasia)

**2. Aspect Ratio**
Escolha proporção:
- 1:1 (quadrado)
- 16:9 (widescreen)
- 9:16 (vertical/stories)
- 4:3, 3:2, etc.

**3. Número de Imagens**
- 1, 2, 4 ou 8 variações
- Quanto mais, mais tokens usa

**4. Guidance Scale**
- Baixo (5-7): mais criativo
- Médio (7-12): balanceado
- Alto (12-20): segue prompt à risca

**Quando Usar Leonardo:**
✅ Precisa de arte fantasia/RPG
✅ Quer controle fino
✅ Precisa de formatos específicos
✅ Quer experimentar modelos diferentes

#### Ideogram - Especialista em Texto

**O Diferencial:**
Melhor ferramenta gratuita para **texto EM imagens**.

**Setup:**
1. Acesse [ideogram.ai](https://ideogram.ai)
2. Crie conta
3. Comece a criar (25 imagens/dia grátis)

**Como Usar Texto:**

```
Exemplo de prompt:
"Um poster motivacional com o texto 'NEVER GIVE UP' em letras
grandes e bold, fundo gradiente azul para roxo, estilo moderno
e inspirador, tipografia sans-serif, layout centralizado"
```

**Dica:** Coloque o texto desejado entre aspas no prompt.

**Quando Usar Ideogram:**
✅ Posts com frases
✅ Logos com texto
✅ Cartazes
✅ Thumbnails com títulos

### Aula 4: Edição Básica com Canva IA

**Duração:** 1.5 horas

#### Canva - Sua Ferramenta de Finalização

**Por Que Canva?**
✅ Interface intuitiva
✅ Templates prontos
✅ IA integrada
✅ Gratuito (com upgrades opcionais)
✅ Exportação fácil

**Recursos IA Gratuitos:**

**1. Magic Edit**
- Edita partes da imagem
- Adiciona ou remove elementos

**2. Background Remover**
- Remove fundo (limitado no grátis)

**3. Magic Eraser**
- Remove objetos indesejados

**4. Text to Image**
- Gera imagens direto no Canva

#### Workflow: IA → Canva

**Passo a Passo:**

**1. Crie Imagem Base em IA**
- Bing, Leonardo, etc.
- Baixe em alta resolução

**2. Importe no Canva**
- Crie novo design
- Escolha dimensões (ou use template)
- Upload da imagem IA

**3. Ajustes Básicos**
- Crop/cortar
- Ajustar posição
- Redimensionar

**4. Adicione Elementos**
- Texto
- Formas
- Ícones
- Filtros

**5. Finalize**
- Ajuste cores (saturação, brilho, contraste)
- Aplique filtros se necessário
- Verifique qualidade

**6. Exporte**
- Download como PNG (melhor qualidade)
- ou JPG (menor tamanho)

#### Templates Úteis no Canva

Para este curso, use templates de:
- Instagram Post (1080x1080)
- Instagram Story (1080x1920)
- LinkedIn Post (1200x627)
- YouTube Thumbnail (1280x720)
- Facebook Cover (1640x856)

### Aula 5: Workflow Completo - Da Ideia à Imagem Final

**Duração:** 1 hora

#### Seu Processo Profissional

**FASE 1: PLANEJAMENTO (5-10 min)**

1. Defina objetivo
   - Para quê é a imagem?
   - Qual emoção deve transmitir?

2. Defina especificações
   - Formato (quadrado, vertical, horizontal)
   - Cores predominantes
   - Estilo visual

3. Reúna referências
   - Procure 2-3 imagens similares ao desejado
   - Analise o que te atrai nelas

**FASE 2: CRIAÇÃO (10-20 min)**

4. Escreva o prompt
   - Use estrutura do Módulo 3
   - Seja específico

5. Escolha a ferramenta
   - Bing: geral, fotográfico
   - Leonardo: arte, fantasia
   - Ideogram: precisa de texto

6. Gere primeira versão
   - Crie 4 variações
   - Escolha a melhor

7. Itere se necessário
   - Ajuste prompt
   - Gere novamente
   - Compare versões

**FASE 3: REFINAMENTO (10-15 min)**

8. Edite no Canva
   - Importe a imagem
   - Ajuste composição
   - Adicione texto se necessário
   - Aplique filtros sutis

9. Ajustes finais
   - Cores
   - Contraste
   - Saturação
   - Nitidez

**FASE 4: EXPORTAÇÃO (2-5 min)**

10. Revise
    - Zoom in para ver detalhes
    - Confira se atende objetivo
    - Aplicar checklist do Módulo 2

11. Exporte
    - Formato correto
    - Resolução adequada
    - Nome de arquivo descritivo

12. Organize
    - Salve em pasta específica
    - Guarde o prompt usado
    - Anote configurações que funcionaram

**TEMPO TOTAL: 30-50 minutos por imagem** (com prática, cai para 10-15 min)
