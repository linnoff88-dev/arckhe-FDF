# 🎨 Projeto Final - Trilha Iniciante
## Pack de Imagens para Redes Sociais

**Trilha:** Iniciante
**Duração:** 1 semana
**Dificuldade:** ⭐⭐ Iniciante

---

## 🎯 Objetivo do Projeto

Criar um **pack completo de 15 imagens profissionais** para alimentar suas redes sociais por 1 semana, aplicando todos os conhecimentos adquiridos nos 4 módulos.

Este projeto vai:
- ✅ Consolidar seu aprendizado
- ✅ Gerar um portfólio inicial
- ✅ Dar conteúdo real para usar
- ✅ Qualificar você para o certificado

---

## 📦 Entregáveis

### Total: 15 Imagens

**Instagram/Facebook (6 imagens):**
- 3 posts para feed (1080x1080 pixels)
- 3 stories (1080x1920 pixels)

**LinkedIn (3 imagens):**
- 3 imagens para posts (1200x627 pixels)

**YouTube (3 imagens):**
- 3 thumbnails (1280x720 pixels)

**Twitter/X (3 imagens):**
- 3 banners/headers (1500x500 pixels)

---

## 🎨 Requisitos do Projeto

### 1. Identidade Visual Coerente

Todas as 15 imagens devem seguir uma **identidade visual unificada**:

**Escolha e mantenha:**
- [ ] Paleta de 3-4 cores principais
- [ ] Estilo visual consistente (fotográfico, ilustração, 3D, etc.)
- [ ] Tipo de iluminação predominante
- [ ] Atmosfera/mood geral

**Exemplo de Identidade:**
```
Paleta: Azul (#3B82F6), Branco (#FFFFFF), Cinza claro (#F3F4F6)
Estilo: Fotografia profissional moderna
Iluminação: Luz natural suave
Atmosfera: Profissional, clean, inspirador
```

### 2. Uso de Múltiplas Ferramentas

Você DEVE usar pelo menos 2 ferramentas diferentes:

**Opções:**
- [ ] Bing Image Creator
- [ ] Leonardo.ai
- [ ] Ideogram
- [ ] Canva (para edição/finalização)

**Exemplo:**
- Gerar imagens base no Bing
- Finalizar todas no Canva

### 3. Aplicação dos Fundamentos

Cada imagem deve demonstrar:

**Composição (Módulo 2):**
- [ ] Regra dos terços ou composição intencional
- [ ] Ponto focal claro
- [ ] Espaço negativo adequado

**Cores (Módulo 2):**
- [ ] Paleta harmoniosa
- [ ] Cores transmitem emoção adequada
- [ ] Contraste suficiente

**Prompts (Módulo 3):**
- [ ] Prompts bem estruturados
- [ ] Uso de vocabulário correto
- [ ] Iteração e refinamento

### 4. Propósito e Contexto

Defina para qual marca/pessoa/projeto são estas imagens.

**Opções:**
- Seu próprio negócio/marca pessoal
- Um projeto fictício
- Uma causa que você apoia
- Portfolio genérico profissional

## 📋 Passo a Passo Detalhado

### Semana do Projeto

**Dia 1: Planejamento (2h)**

**1. Defina seu tema/marca**
- Quem/o que você vai representar?
- Qual é a mensagem?
- Quem é o público-alvo?

**2. Crie identidade visual**
- Escolha paleta de cores (use Coolors.co)
- Defina estilo visual
- Escolha atmosfera/mood
- Crie moodboard (salve 5-10 referências)

**3. Planeje as 15 imagens**
Faça lista do que cada uma vai mostrar:
```
Feed 1: [descrição]
Feed 2: [descrição]
Feed 3: [descrição]
Story 1: [descrição]
... e assim por diante
```

---

**Dia 2-3: Criação - Parte 1 (4h)**

**4. Crie os 6 primeiros (Instagram/Facebook)**

Para cada imagem:
1. Escreva prompt detalhado
2. Gere 4 variações
3. Escolha a melhor
4. Itere se necessário
5. Salve imagem + prompt

**Checklist por imagem:**
- [ ] Segue identidade visual?
- [ ] Tamanho correto?
- [ ] Qualidade boa?
- [ ] Atinge objetivo?

---

**Dia 4-5: Criação - Parte 2 (4h)**

**5. Crie as 9 restantes (LinkedIn, YouTube, Twitter)**

Mesmo processo do dia 2-3.

**Dica:** Use variações dos mesmos temas para manter coerência.

---

**Dia 6: Edição e Finalização (3h)**

**6. Importe todas no Canva**

Para cada imagem:
1. Ajuste se necessário (crop, posição)
2. Adicione texto se apropriado
3. Ajuste cores (leve correção)
4. Aplique filtro sutil se necessário

**7. Exporte todas**
- Formato: PNG (melhor qualidade) ou JPG (menor tamanho)
- Nomeie: `[rede]-[tipo]-[numero].png`
  - Exemplo: `instagram-feed-01.png`

---

**Dia 7: Documentação e Entrega (2h)**

**8. Crie documento do projeto**

Inclua:
- Briefing (tema, objetivo, público)
- Identidade visual (paleta, estilo, mood)
- As 15 imagens organizadas
- Prompts usados para cada uma
- Ferramentas utilizadas
- Desafios e aprendizados
- Auto-avaliação

**9. Organize arquivos**
```
projeto-final/
├── briefing.md
├── identidade-visual.md
├── instagram/
│   ├── feed/
│   │   ├── feed-01.png
│   │   ├── feed-02.png
│   │   └── feed-03.png
│   └── stories/
│       ├── story-01.png
│       ├── story-02.png
│       └── story-03.png
├── linkedin/
│   ├── post-01.png
│   ├── post-02.png
│   └── post-03.png
├── youtube/
│   ├── thumb-01.png
│   ├── thumb-02.png
│   └── thumb-03.png
├── twitter/
│   ├── banner-01.png
│   ├── banner-02.png
│   └── banner-03.png
└── prompts.md
```

## ✅ Critérios de Avaliação

### Seu projeto será avaliado em:

**1. Coerência Visual (30 pontos)**
- [ ] Identidade visual clara e consistente (10)
- [ ] Paleta de cores harmoniosa em todas (10)
- [ ] Estilo visual unificado (10)

**2. Qualidade Técnica (25 pontos)**
- [ ] Composição bem executada (10)
- [ ] Iluminação adequada (5)
- [ ] Resolução e qualidade corretas (5)
- [ ] Sem erros visuais graves (5)

**3. Aplicação do Conteúdo (25 pontos)**
- [ ] Uso correto de fundamentos visuais (10)
- [ ] Prompts bem estruturados (10)
- [ ] Demonstra aprendizado dos módulos (5)

**4. Criatividade e Originalidade (10 pontos)**
- [ ] Visão criativa própria (5)
- [ ] Não é apenas cópia de referências (5)

**5. Documentação (10 pontos)**
- [ ] Projeto bem documentado (5)
- [ ] Prompts salvos e organizados (5)

**Pontuação:**
- 90-100: ⭐⭐⭐⭐⭐ Excepcional
- 80-89: ⭐⭐⭐⭐ Excelente
- 70-79: ⭐⭐⭐ Bom
- 60-69: ⭐⭐ Satisfatório
- < 60: ⭐ Precisa melhorar

**Mínimo para certificado: 70 pontos**
