## 📚 Conteúdo do Módulo

### Aula 1: O Que Faz Uma Imagem "Funcionar"

**Duraçêo:** 1.5 horas

#### Os 5 Elementos Essenciais

**1. Propósito Claro**
Uma imagem boa tem um objetivo:
- Emocionar
- Informar
- Vender
- Inspirar
- Entreter

❌ **Ruim:** "Quero uma imagem bonita"
✅ **Bom:** "Quero uma imagem que transmita confiança e profissionalismo"

**2. Foco Visual**
O olhar deve saber para onde ir.

**Teste rápido:**
- Olhe a imagem por 3 segundos
- Feche os olhos
- O que você lembra?

Se nêo lembra de nada específico → sem foco.

**3. Harmonia**
Todos os elementos devem "conversar" entre si.

**Elementos:**
- Cores complementam (nêo brigam)
- Estilos alinhados (nêo misturados aleatoriamente)
- Proporções equilibradas

**4. Emoçêo**
Boas imagens fazem você SENTIR algo.

**Pergunte-se:**
- O que esta imagem me faz sentir?
- É o que deveria fazer sentir?

**5. Qualidade Técnica**
- Resoluçêo adequada
- Sem artefatos ou distorções
- Iluminaçêo coerente

#### Framework de Análise

Use este framework para avaliar qualquer imagem:

```
□ PROPÓSITO: A imagem tem um objetivo claro?
□ FOCO: Meu olhar sabe para onde ir?
□ HARMONIA: Os elementos se complementam?
□ EMOÇêO: Me faz sentir algo?
□ QUALIDADE: Está tecnicamente bem executada?
```

Se 4+ estêo ✅ = Imagem funciona
Se 3 ou menos = Precisa melhorar

### Aula 2: Composiçêo Explicada Para Iniciantes

**Duraçêo:** 2 horas

#### Regra dos Terços (Mais Importante!)

Imagine sua imagem dividida em 9 partes iguais (grade 3x3):

```
+-----+-----+-----+
|     |     |     |
|  •  |     |  •  |
+-----+-----+-----+
|     |     |     |
|     |     |     |
+-----+-----+-----+
|     |     |     |
|  •  |     |  •  |
+-----+-----+-----+
```

**Regra:** Coloque elementos importantes nos **•** (interseções).

**Por que funciona?**
Nosso olho naturalmente vai para esses pontos.

**Exemplos práticos:**
- Retrato: olhos na linha superior
- Paisagem: horizonte na linha inferior ou superior (nunca no meio!)
- Produto: no terço direito

#### Espaço Negativo (Respiro Visual)

**O que é:**
Áreas vazias ao redor do elemento principal.

**Por que importa:**
- Dá destaque ao principal
- Transmite elegância
- Facilita leitura

❌ **Ruim:** Imagem lotada, sem respiro
✅ **Bom:** Elemento principal com espaço ao redor

#### Hierarquia Visual

**O que deve aparecer primeiro?**

**Tamanho:**
Maior = mais importante

**Contraste:**
Mais contraste = mais atençêo

**Posicionamento:**
Topo e esquerda = visto primeiro

#### Equilíbrio

**Simétrico:**
- Espelhado
- Formal e estável
- Bom para: corporativo, elegante

**Assimétrico:**
- Dinâmico
- Informal e energético
- Bom para: criativo, moderno

#### Direçêo do Olhar

**Linhas guiam o olhar:**
- Diagonais = dinamismo
- Horizontais = calma
- Verticais = força
- Curvas = movimento suave

**Dica de IA:**
No prompt, especifique: "diagonal composition" ou "centered composition"

### Aula 3: Cores Que Emocionam e Vendem

**Duraçêo:** 2 horas

#### Psicologia das Cores

**🔴 Vermelho**
- Emoçêo: Paixêo, energia, urgência
- Uso: Vendas, comida, alerta
- Evite: Finanças, saúde mental

**🔵 Azul**
- Emoçêo: Confiança, calma, profissionalismo
- Uso: Tech, saúde, finanças
- Evite: Comida (reduz apetite)

**🟢 Verde**
- Emoçêo: Natureza, crescimento, saúde
- Uso: Sustentabilidade, bem-estar, dinheiro
- Evite: Luxo high-end

**🟡 Amarelo**
- Emoçêo: Otimismo, alegria, atençêo
- Uso: Crianças, felicidade, energia
- Evite: Excesso (cansa os olhos)

**🟣 Roxo**
- Emoçêo: Luxo, criatividade, mistério
- Uso: Beleza, luxo, espiritualidade
- Evite: Corporativo tradicional

**🟠 Laranja**
- Emoçêo: Entusiasmo, criatividade, diversêo
- Uso: Call-to-action, jovem, energia
- Evite: Corporativo sério

**⚫ Preto**
- Emoçêo: Elegância, poder, sofisticaçêo
- Uso: Luxo, moda, minimalismo
- Evite: Infantil, alegre

**⚪ Branco**
- Emoçêo: Pureza, simplicidade, espaço
- Uso: Minimalismo, limpeza, médico
- Evite: Sozinho (pode ser estéril)

#### Harmonias de Cores

**Monocromática**
Uma cor em diferentes tons.
- Simples e elegante
- Fácil de acertar
- Pode ser monótono

**Análoga**
Cores vizinhas no círculo cromático.
- Harmoniosa
- Natural
- Boa para iniciantes

**Complementar**
Cores opostas no círculo.
- Alto contraste
- Vibrante
- Cuidado com excesso

**Tríade**
3 cores igualmente espaçadas.
- Balanceada
- Vibrante
- Mais complexa

#### Dicas Práticas

**Para Prompts:**
```
✅ "warm color palette" = cores quentes
✅ "cool tones" = tons frios
✅ "pastel colors" = cores pastel
✅ "vibrant colors" = cores vibrantes
✅ "monochromatic blue" = monocromático azul
```

**Ferramentas Grátis:**
- [Coolors.co](https://coolors.co) - Gerador de paletas
- [Adobe Color](https://color.adobe.com) - Roda de cores
- [Paletton](https://paletton.com) - Harmonias

### Aula 4: Luz e Contraste na Prática

**Duraçêo:** 1.5 horas

#### Tipos de Iluminaçêo

**1. Golden Hour (Hora Dourada)**
- Luz suave e quente
- Sombras longas
- Romântico e acolhedor
- **Prompt:** "golden hour lighting"

**2. Blue Hour (Hora Azul)**
- Crepúsculo
- Tons azuis
- Misterioso e dramático
- **Prompt:** "blue hour atmosphere"

**3. Hard Light (Luz Dura)**
- Sombras definidas
- Alto contraste
- Dramático
- **Prompt:** "hard lighting, strong shadows"

**4. Soft Light (Luz Suave)**
- Sombras difusas
- Delicado
- Suave e acolhedor
- **Prompt:** "soft diffused lighting"

**5. Backlight (Contraluz)**
- Luz atrás do objeto
- Silhueta
- Atmosférico
- **Prompt:** "backlit, rim light"

**6. Studio Light**
- Controlada
- Profissional
- Limpa
- **Prompt:** "studio lighting, professional"

#### Contraste

**O que é:**
Diferença entre claro e escuro.

**Alto Contraste:**
- Dramático
- Chama atençêo
- Moderno
- Exemplo: Preto e branco

**Baixo Contraste:**
- Suave
- Delicado
- Vintage
- Exemplo: Tons pastel

**Médio Contraste:**
- Balanceado
- Natural
- Versátil

**Para IA:**
```
Alto: "high contrast, dramatic"
Baixo: "low contrast, soft, muted"
Médio: "natural lighting, balanced"
```

#### Direçêo da Luz

**Frontal:**
- Ilumina tudo
- Sem sombras
- Simples mas plano

**Lateral:**
- Cria profundidade
- Textura visível
- Dramático

**Superior:**
- Sombras embaixo
- Dramático
- Pode ser duro

**Inferior:**
- Nêo natural
- Terror, drama
- Use com cuidado

### Aula 5: Como Analisar Se Uma Imagem É Boa

**Duraçêo:** 1 hora

#### Checklist Definitivo

**COMPOSIÇêO**
- [ ] Tem um ponto focal claro?
- [ ] Segue regra dos terços?
- [ ] Tem equilíbrio visual?
- [ ] Tem espaço negativo adequado?

**COR**
- [ ] Paleta de cores harmoniosa?
- [ ] Cores transmitem emoçêo certa?
- [ ] Nêo há mais de 3-4 cores dominantes?
- [ ] Contraste adequado?

**LUZ**
- [ ] Iluminaçêo é coerente?
- [ ] Sombras fazem sentido?
- [ ] Atmosfera desejada foi alcançada?
- [ ] Contraste funciona?

**TÉCNICA**
- [ ] Resoluçêo boa?
- [ ] Sem artefatos visuais?
- [ ] Proporções corretas?
- [ ] Qualidade geral profissional?

**EMOÇêO/PROPÓSITO**
- [ ] Transmite a emoçêo desejada?
- [ ] Atinge o objetivo?
- [ ] Adequada ao público-alvo?
- [ ] Impactante ou memorável?

**Pontuaçêo:**
- 18-20 ✅ = Excelente
- 15-17 ✅ = Boa
- 12-14 ⚠️ = Precisa ajustes
- < 12 ❌ = Refazer

## 🎯 Exercícios Práticos

### Exercício 1: Análise de Composiçêo (1h)

Encontre 5 imagens famosas e analise:
1. Onde está o ponto focal?
2. Segue regra dos terços?
3. Que tipo de equilíbrio usa?
4. Como as linhas guiam o olhar?

**Entrega:** Análise escrita + imagens anotadas

---

### Exercício 2: Paletas de Cores (1h)

Crie 3 paletas para diferentes emoções:
1. Calma e profissional
2. Energético e jovem
3. Luxuoso e elegante

Use [Coolors.co](https://coolors.co)

**Entrega:** 3 paletas salvas

---

### Exercício 3: Luz e Atmosfera (1h)

Usando IA (Bing Image Creator), crie a MESMA cena com 3 luzes diferentes:
1. Golden hour
2. Dramatic hard light
3. Soft diffused light

**Entrega:** 3 imagens + reflexêo sobre diferenças

---

### Exercício 4: Análise Comparativa (1h)

Encontre 2 versões da mesma imagem:
- Uma BEM composta
- Uma MAL composta

Aplique o checklist e documente diferenças.

**Entrega:** Análise completa
